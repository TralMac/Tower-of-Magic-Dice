## 0. 一句话 & 设计支柱

**一句话**：经典魔塔的「爬层 + 钥匙门 + 资源规划」，把固定数值战斗换成**骰子对抗**，每个角色就是一套骰子，用技能树和遗物去「驯服运气」。

| 支柱 | 含义 | 落到设计上 |
|---|---|---|
| **骰子即角色** | 3d4、2d6、1d12……不同骰型 = 不同玩法 | 各角色**期望值接近（≈7）**，区别在**方差**和**操控骰子的方式** |
| **可计算的运气** | 魔塔的乐趣是「算」，骰子带来的是「赌」 | 怪物手册显示**胜率 / 期望掉血 / 最坏情况**，让玩家依然能做规划 |
| **越打越破** | 护甲会磨损，战斗有节奏变化 | 前几回合拼防御，护甲碎后伤害陡增；群体怪专克护甲 |
| **每一环都能被改写** | 战斗流程每个阶段都有遗物钩子 | 统一的事件时序 + 修正顺序，保证遗物可组合、不打架 |

## 1. 核心循环

```
选角色(骰型) → 进入塔层 → 探索：开门/拿钥匙/捡宝石药水/遇事件
      ↑                         ↓
  层间商店/祭坛  ←  击败怪物 → 金币 + 经验 → 升级 → 技能点
      ↑                         ↓
  每 5/10 层首领 → 遗物三选一            特质（事件给予，好坏都有）
```

- **局内**：魔塔式地图，HP 是跨战斗的核心资源（沿用魔塔的「血量即货币」）。
- **局外**【建议】：Roguelite 形式——地图结构手工设计，**怪物配置、宝箱、事件、遗物从池中随机**。兼顾魔塔的谜题感和重玩性。【待定 Q1】

## 2. 骰子基础规则

### 2.1 三种骰池

每个单位（玩家和怪物同规则）有三组骰：

| 骰池 | 作用 | 说明 |
|---|---|---|
| **攻击骰** | 攻击时投掷 | 角色的「本命骰」，决定角色身份 |
| **防御骰（护甲）** | 被攻击且未闪避时投掷 | 会**磨损**（见 2.2） |
| **闪避骰** | 被攻击时先投 | 通常很小（d2~d6），重甲怪可以没有 |

> 【待定 Q2】你说的「角色 = 骰子」，我理解为**攻击骰是本命骰**，防御 / 闪避是另配的小骰池。另一种更极简的做法是一个角色的所有投掷都用同一种骰型。

### 2.2 护甲等级 & 磨损（核心新机制）

把你的例子「2d6 防御失败 → 1d6+1d4」规则化：

- **护甲等级 = 所有防御骰的面数之和**。2d6 = 12 级，1d6+1d4 = 10 级。
- **每降 1 级：面数最小的那颗骰子 −1 面**（网页游戏可以有 d5、d3 这种实体不存在的骰子）。
- 骰子降到 d1 时**碎裂移除**。

```
2d6 → d6+d5 → d6+d4 → d6+d3 → d6+d2 → d6 → d5 → d4 → d3 → d2 → 无甲
 12     11      10      9       8      6    5    4    3    2
```

- 防御成功 −1 级，防御失败 −2 级（与你的设定一致）。
- 【建议】**护甲每场战斗结束后恢复满**。如果改成跨战斗持续，就需要「修甲」资源（类似药水），难度和复杂度都会上去。【待定 Q3】
- 【建议】同一套规则也用来**成长**：防御宝石 = 护甲上限 +1 级（给最小的骰子 +1 面）；攻击宝石同理。成长和磨损共用一套「面数阶梯」，玩家只需要学一次。

### 2.3 修正顺序（防止遗物互相打架）

每次投骰按以下顺序结算，**同一层内先攻击方、后防御方，同一方按获得顺序**：

1. **投骰前**：改骰池（加骰、换骰、「减少对面骰子」）
2. **投骰**
3. **骰面操作**：重投、锁定、翻面、把某颗骰改成指定值
4. **加减值**：技能 +1、特质 ±1、高打低 +1、遗物加值
5. **乘算**：暴击 ×2 等
6. **下限截断**：最终点数不低于 0

## 3. 战斗流程（状态机）

```
[战斗开场] ─→ [回合判定] ─→ [攻击声明] ─→ [攻击投骰] ─→ [闪避判定]
                  ↑                                        │ 失败
                  │                                        ↓
           [战斗结束检查] ←─ [受到伤害] ←───────────── [防御判定]
                  │ 一方 HP ≤ 0
                  ↓
             [战斗结算]
```

| # | 阶段 | 做什么 | 遗物钩子（先攻击方 → 后防御方） |
|---|---|---|---|
| 1 | 战斗开场 | 初始化护甲、群体层数、开场特效 | `onBattleStart` |
| 2 | 回合判定 | 决定本回合谁先动（见 3.1） | `onTurnStart` |
| 3 | 攻击声明 | 确定段数（群体）、目标 | `onAttackDeclare` |
| 4 | 攻击投骰 | 按 2.3 结算攻击点数 **A** | `onAttackRoll` |
| 5 | 闪避判定 | 防御方投闪避 **E**；若 **A ≤ E** → 闪避，本段结束 | `onDodgeCheck` / `onDodged` |
| 6 | 防御判定 | 防御方投护甲 **D**；成功/失败，护甲 −1/−2 | `onDefenseCheck` / `onArmorBreak` |
| 7 | 受到伤害 | 扣 HP = max(0, A − D) | `onDamageTaken` / `onDamageDealt` |
| 8 | 结束检查 | 有一方 HP ≤ 0 → 结算，否则回到 2 | `onTurnEnd` |
| 9 | 战斗结算 | 经验、金币、掉落、特质触发 | `onBattleEnd` / `onKill` |

### 3.1 回合判定【建议】

你写的「即时回合制」有两种落地方式【待定 Q4】：

- **方案 A（推荐 MVP）**：每回合双方各行动一次，**速度高者先手**，同速玩家先手。简单、方便算。
- **方案 B**：ATB 行动条。每个单位按速度充能，满了就行动，速度差距大时快的一方可以连动。更有「即时」感，但预测难度更高。

### 3.2 玩家在战斗中的决策点【建议】

魔塔原版战斗是全自动的。这里建议做成**半自动**：默认自动结算（可以 2×/4× 加速），只有在**投骰完成后**（第 4 步与第 5/6 步之后）弹出一个窗口，玩家决定要不要用主动技能（重投、+1、削对面骰子）。不用就自动继续。这样大部分战斗依然很快，关键一投由玩家自己掌控。

## 4. 判定公式（单段攻击）

```
A = 攻击骰结果 + 修正                     （高打低、特质、技能、遗物）
E = 闪避骰结果 + 修正
if A ≤ E:            → 闪避成功：无伤害，护甲不变
D = 防御骰结果 + 修正
if A > D:            → 防御失败：HP −(A − D)，护甲 −2 级
else:                → 防御成功：无伤害，护甲 −1 级
```

**例**：剑士（攻 2d6）打骷髅兵（闪 1d2，防 2d6）
1. 剑士投出 9。骷髅兵闪避投出 2 → 9 > 2，闪避失败。
2. 骷髅兵防御投出 6 → 9 > 6，防御失败：骷髅兵 −3 HP，护甲 2d6 → d6+d4。
3. 下一次骷髅兵的防御期望从 7 降到 6，护甲越打越薄。

## 5. 群体机制

- 群体 N：每次攻击变成 **1 + N 段**，每一段**独立**投攻击骰，独立走闪避 / 防御 / 伤害。
- 模拟里的重要发现：**群体对护甲是克星**。每一段都会磨掉 1~2 级护甲，所以群体怪单段骰子必须小（1d4~1d6），否则会碾压高护甲角色。
- 【建议·可选】**群体随血量瓦解**：群体 N 的怪每损失 1/(N+1) 的最大 HP，群体层数 −1。表现为「打散一群哥布林」，也让玩家的爆发更有价值。
- 【建议】给玩家留应对手段：群攻 / 溅射类遗物（如「横扫：伤害溢出给下一段」）、「对群体 +X 点」的特质。

## 6. 角色 & 技能树

设计原则：**期望伤害接近，分布不同**。

| 角色 | 攻击骰 | 范围 | 期望 | 方差 | 玩法关键词 |
|---|---|---|---|---|---|
| 铁卫「三棱」 | 3d4 | 3–12 | 7.5 | 低 | 稳定、逐骰加成、护甲 |
| 剑士「双子」 | 2d6 | 2–12 | 7.0 | 中 | 对子、重投 |
| 赌徒「孤注」 | 1d12 | 1–12 | 6.5 | 高 | 爆骰、暴击、豪赌 |
| 咒术师「蚀骨」 | 1d8+1d4 | 2–12 | 7.0 | 中 | 削骰、诅咒、控场 |

初始面板（v0.1，见第 11 节模拟）：

| 角色 | 攻 | 防 | 闪 | HP | 速 |
|---|---|---|---|---|---|
| 铁卫 | 3d4 | 2d6 | 1d2 | 50 | 2 |
| 剑士 | 2d6 | 1d6+1d4 | 1d4 | 50 | 3 |
| 赌徒 | 1d12 | 1d6 | 1d6 | 45 | 4 |
| 咒术师 | 1d8+1d4 | 2d4 | 1d4 | 50 | 3 |

### 6.1 技能资源【建议】：骰能

主动技能消耗**骰能**。获取方式：**每投出一颗 1 点，获得 1 骰能**（另加每场战斗开场 +1）。
→ 运气差会自动积攒「翻盘资源」，天然的保底机制，也让 3d4（骰子多、出 1 概率高）和 1d12 拿资源的节奏不同。

### 6.2 技能树（每角色 3 条分支，每支 4~5 个节点，示例）

**铁卫「三棱」3d4**：骰子越多，每颗骰的加成越赚

- *匠心*：每颗攻击骰 +1 面（3d4 → 3d5）｜**本次骰子 +1（每颗）**——3 颗骰子吃到 +3
- *壁垒*：防御成功时护甲不磨损（每场 1 次）｜战斗中修复 2 级护甲（2 骰能）
- *增殖*：骰池 +1 颗 d2｜终极：攻击骰池 4d4

**剑士「双子」2d6**：围绕「对子」

- *剑技*：**重投一次**（1 骰能，任选一颗骰重投）｜重投后取较高
- *双生*：投出对子时追加一段攻击｜对子必定穿透闪避
- *架势*：上一段被防御住 → 下一段 +2｜防御成功时反击 1d4

**赌徒「孤注」1d12**：放大方差

- *爆骰*：投出最大值时再投一次并累加（可连爆）
- *豪赌*：主动技能「梭哈」：本次攻击 ×2，但没打穿防御就自损同等 HP
- *千术*：投出 1 时改为 12（每场 1 次）｜看清对手下一次投骰结果（预知）

**咒术师「蚀骨」d8+d4**：**减少对面骰子**

- *侵蚀*：主动技能：对面下一次投骰最大的那颗骰子 −2 面（1 骰能）
- *腐甲*：攻击命中时额外 −1 级护甲｜对无甲目标伤害 +2
- *诅咒*：给敌人挂「虚弱」（防 −1）/「无力」（攻 −1），复用特质系统

> 节点数值待第二轮模拟后再定；重点先验证「每个角色的核心技能是否让它和其他角色玩起来不一样」。

## 7. 特质

特质 = 长期被动修正，由**开局随机 / 事件 / 诅咒 / 祭坛**给予。玩家和怪物共用同一套特质。

| 类型 | 特质 | 效果 | 来源举例 |
|---|---|---|---|
| 负面 | **体弱** | 防御点数 −1 | 开局、被诅咒 |
| 负面 | **肌无力** | 攻击点数 −1 | 开局、中毒事件 |
| 负面 | 迟钝 | 速度 −1 | 事件 |
| 负面 | 脆骨 | 防御失败时护甲额外 −1 级 | 恶魔契约代价 |
| 正面 | 坚韧 | 防御点数 +1 | 祭坛 |
| 正面 | 灵巧 | 闪避点数 +1 | 事件 |
| 正面 | 屠群者 | 对群体怪攻击 +1 | 击杀 20 只群体怪 |
| 混合 | 狂战士 | 攻击 +2，防御 −2 | 恶魔契约 |

规则【建议】：同名特质**可叠层**（体弱×2 = 防 −2）；可以在神殿花钱净化负面特质；事件常给「正面 + 负面」的打包交易（参考杀戮尖塔的诅咒牌）。

## 8. 高打低 & 其它修正

**高打低**：攻击方「高」于防御方时，攻击点数 +1；特定角色 / 遗物额外加成。

「高」指什么需要你确认【待定 Q5】，可选：
- (a) **等级 / 阶位**比对方高（模拟器目前按这个实现）
- (b) **攻击骰阶**（面数和）比对方的护甲等级高
- (c) 地形：站在高处 / 楼层更高
- (d) 当前 HP 比对方高（「乘胜追击」）

【建议】做成对称机制：怪物高打低你也 +1。这样会形成「越级打怪更难」的自然梯度，符合魔塔「先刷够再挑战」的节奏。

## 9. 遗物

- 每个遗物 = **钩子（第 3 节的阶段）+ 条件 + 效果**，数据驱动，便于配表。
- 稀有度：普通 / 稀有 / 传说 / 角色专属（如「铁卫专属：高打低额外 +1」）。

| 遗物 | 钩子 | 效果 |
|---|---|---|
| 灌铅骰 | onAttackRoll | 攻击骰最低点数视为 2 |
| 镜面盾 | onDefenseCheck | 防御成功且 D ≥ 2A 时，反弹 A 点伤害 |
| 第六感 | onDodgeCheck | 每场第一次被攻击必定闪避 |
| 碎甲锤 | onArmorBreak | 打碎敌方一颗护甲骰时，骰能 +1 |
| 吸血牙 | onDamageDealt | 造成 ≥ 5 伤害时回复 1 HP |
| 赌徒的硬币 | onBattleStart | 50%：本场攻 +2；50%：本场攻 −1 |
| 王冠 | onAttackRoll | 高打低加成 +1（角色专属：铁卫） |
| 横扫 | onDamageDealt | 对群体怪溢出伤害扣到下一层 |

## 10. 魔塔层设计

| 魔塔原版元素 | 本作对应 |
|---|---|
| 红 / 蓝宝石（攻 / 防 +N） | 攻击 / 防御骰阶 +1（面数 +1）或平值 +1 |
| 血瓶 | 保留，HP 依然是核心资源 |
| 黄 / 蓝 / 红钥匙 + 门 | 保留 |
| 怪物手册（显示伤害） | **概率手册**：胜率、期望掉血、90% 最坏掉血（前端跑 2000 次模拟即可） |
| 商店（金币换属性） | 商店 + **骰匠**（改骰型、换骰）+ 神殿（净化特质） |
| 隐藏墙 / 捷径 | 保留，可以放事件和遗物 |
| 首领层 | 每 5/10 层；首领带专属机制（如每回合 +1 群体） |

【建议】**战前确认**：胜率 < 50% 的怪，交战前弹窗提示。魔塔里「不能撤退」本身就是规划压力；骰子版本可以加入有代价的撤退（失去 X 金币 / 获得负面特质）。【待定 Q6】

## 11. 数值初稿 & 模拟结果

模拟器：`node sim/battle-sim.mjs [次数]`。只算基础规则（不含技能 / 遗物），护甲每场重置，速度高者先手。每组 20000 场，胜率与 HP 均为**无技能、1 级**的基线。

怪物：

| 怪物 | 攻 | 防 | 闪 | HP | 速 | 备注 |
|---|---|---|---|---|---|---|
| 绿史莱姆 | 1d4 | 1d4 | — | 10 | 1 | |
| 蝙蝠群 | 1d4 | 1d2 | 1d6 | 8 | 5 | 群体 1 |
| 骷髅兵 | 2d4 | 2d6 | 1d2 | 16 | 2 | |
| 哥布林群 | 1d6 | 1d4 | 1d4 | 18 | 3 | 群体 2 |
| 兽人战士 | 2d6 | 2d6 | 1d2 | 28 | 2 | 阶位 2（高打低） |
| 骨龙（首领） | 2d8 | 2d8 | 1d4 | 60 | 3 | 阶位 3，群体 1 |

胜率 / 平均掉血：

| 怪物 | 铁卫 | 剑士 | 赌徒 | 咒术师 |
|---|---|---|---|---|
| 绿史莱姆 | 100% / 0.0 | 100% / 0.1 | 100% / 0.3 | 100% / 0.1 |
| 蝙蝠群 | 100% / 0.2 | 100% / 0.3 | 100% / 1.1 | 100% / 0.5 |
| 骷髅兵 | 100% / 4.3 | 100% / 8.3 | 99.6% / 13.9 | 100% / 12.0 |
| 哥布林群 | 100% / 9.8 | 100% / 7.5 | 98.9% / 12.2 | 99.8% / 10.9 |
| 兽人战士 | 96% / 27.8 | 79% / 37.4 | 36% / 41.2 | 67% / 41.5 |
| 骨龙 | 0% | 0% | 0% | 0% |

**结论**

1. **防御骰权重很高**：铁卫靠 2d6 护甲在裸装下明显最强。之后要么降护甲，要么给其他角色的技能更多抗衡手段。
2. **护甲磨损让战斗前慢后快**：平均 5~8 回合结束，节奏合适；前 2~3 回合大多被格挡，护甲碎后伤害陡增。
3. **群体 = 破甲器**：哥布林群单段只有 1d6，造成的伤害却和骷髅兵差不多，验证了第 5 节的判断。
4. **赌徒裸装偏弱**：方差机制（爆骰、梭哈）必须在技能里补上，否则没人选。
5. **骨龙是成长检验点**：裸装 0% 胜率符合「首领要求成长」的预期，后续按「第 10 层预期成长」反推首领数值。

## 13. MVP 范围 & 技术建议

**MVP（可玩原型）**

- 1 个角色（剑士 2d6）+ 1 条技能分支（重投）
- 10 层手工地图，6 种怪物，1 个首领
- 完整战斗状态机 + 8 个遗物 + 4 个特质
- 概率版怪物手册

**技术**

- TypeScript；**战斗逻辑与渲染分离**（纯函数的 `combat-core`，渲染层可以选 Canvas / Phaser / React）
- 可设种子的随机数（seeded RNG）→ 能复现 bug、做战斗回放、做每日挑战
- 遗物 / 特质 / 技能全部走**事件钩子 + 数据表**，策划改 JSON 就能加内容
- 怪物手册的概率直接复用 `combat-core` 跑蒙特卡洛（Web Worker 里跑 2000 次，耗时不到 50ms）
