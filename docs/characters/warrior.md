## 3. 背景故事

### 3.1 守誓者

守誓骑士团只有一条誓言：**「剑只为守护而出鞘，绝不为怒火出鞘。」**

凯恩是骑士团里最守规矩的人。他出身于黑石堡山脚下的磨坊村，十四岁入团，二十六岁当上副团长。和他同年入团的罗兰是他的誓约兄弟：两人同吃一锅饭，守同一班夜哨，夜哨无聊时就用一对骨骰赌明天谁擦铠甲。那对骰子是罗兰用同一块骨头刻的，一人一颗。

罗兰常说：「你太能忍了，凯恩。总有一天，你忍下来的东西会一起找上门。」

### 3.2 守门之夜

那年冬天，蛮族大军压境。团长下令：**死守城门，任何人不得出城。**

从城墙上能看见山脚的磨坊村。凯恩看着村子起火，看着火光里奔跑的人影，其中有他的母亲和妹妹。他握剑的手在抖，但没有动。誓言就是誓言，命令就是命令。

天亮时蛮族退了，**一个都没有攻城**。

三天后，凯恩在团长的书房里找到了答案：一封盖着蛮族酋长印记的信，和一箱金币。团长早就把山脚下的村子卖了，换蛮族绕过要塞南下。「死守城门」从来不是为了守城，而是为了不让任何人去救。

### 3.3 无誓之夜

那天夜里，凯恩第一次为怒火拔剑。

他杀了团长，然后是团长的亲卫，然后是所有从走廊冲进来的人。他已经分不清谁拔了剑、谁只是被惊醒。最后一个挡在他面前的是罗兰。罗兰没有拔剑，只是张开手喊他的名字。

等凯恩回过神来，大厅里一片寂静。他的剑上全是血，左手攥着两颗骨骰，一颗是他的，另一颗是从罗兰的手里掉出来的。

### 3.4 登塔

传说世界尽头有一座魔塔，塔顶放着「命运之骰」，掷出它就能改写一段过去。魔塔只接纳罪人。

凯恩剜掉了肩甲上的誓言徽记，带着两颗骰子走进塔里。他想改写那一夜，但他自己也不知道要改哪一刻：

- 改写**守门之夜**：不再服从，冲出城去救村子。可那样他就会成为彻底的怒火。
- 改写**无誓之夜**：咽下怒火，让罗兰活下来。可那样团长的背叛就无人清算，他依然是那个眼睁睁看着家乡燃烧的人。

**这个选择就是玩家的选择**（见第 5 节「终极技能二选一」和第 7 节「结局」）。

## 4. 背景 → 玩法映射

| 背景元素 | 玩法 |
|---|---|
| 守誓者的克制 | **克制之誓**分支：重投、守势、把怒气转化为护甲 |
| 暴怒时分不清敌友 | **怒气**系统；怒气满时进入**暴走**：力量暴涨，但玩家**失去决策窗口**（失控） |
| 两颗骨骰：他自己和罗兰 | 本命骰 2d6；**投出对子 = 罗兰的声音**，触发追加攻击等效果 |
| 剜掉誓言徽记 | 主动技能「卸甲」：亲手磨掉自己的护甲换取怒气 |
| 两个夜晚，两个选择 | 技能树终极节点**二选一**（「赎罪」/「堕怒」），决定结局 |
| 被背叛 | 被格挡、被闪避也会积累怒气：越打不中，越愤怒 |

## 5. 专属系统：怒气【建议，数值待模拟】

和护甲一样，**怒气只在单场战斗内存在**，开场为 0，上限 10，战斗结束清零。

**获得怒气**

| 条件 | 怒气 |
|---|---|
| 受到伤害（防御失败） | +2 |
| 自己的攻击被闪避或被格挡 | +1 |
| 自己的一颗护甲骰碎裂 | +2 |

**怒气效果**

| 怒气 | 效果 |
|---|---|
| 0–1 | 无 |
| 2–5 | 攻击点数 +1 |
| 6–9 | 攻击点数 +2，防御点数 −1 |
| 10 | 进入**暴走** |

**暴走**（持续 3 次自身行动）

- 攻击骰 2d6 → **3d6**
- 闪避骰失效
- **不再弹出决策窗口**：所有投骰自动结算，无法使用技能，也无法撤退
- 结束后怒气清零，获得 2 次行动的「力竭」（速度 −3）

> 设计意图：暴走是一把双刃剑。它能扭转战局，但玩家会暂时失去对战斗的控制，就像凯恩在无誓之夜失去了自己。玩家要决定是压住怒气，还是放任它。

## 6. 技能树

三条分支：克制、焚怒，以及连接两者的「双子」。终极节点**二选一**，选了一个就永久锁定另一个。

### 6.1 克制之誓（理智）：消耗骰能

| 节点 | 效果 |
|---|---|
| 守誓 | 重投一颗攻击骰（1 骰能） |
| 誓盾 | 怒气 ≤ 1 时，防御点数 +1 |
| 沉静 | 主动：清空怒气，每 2 点怒气修复 1 级护甲（0 骰能） |
| 守势 | 防御成功后，下一次攻击 +2 |
| **终极 ·「赎罪」** | 每场 1 次：即将受到致命伤害时保留 1 HP，清空怒气并修满护甲。选择此节点后，**暴走永久禁用** |

### 6.2 焚怒（暴怒）：积累怒气

| 节点 | 效果 |
|---|---|
| 余烬 | 战斗开场怒气 +2 |
| 以血还血 | 受到伤害时，额外 +1 怒气 |
| 卸甲 | 主动：自身护甲 −2 级，怒气 +3（0 骰能） |
| 血怒 | 怒气 ≥ 6 时，打穿防御回复 1 HP |
| **终极 ·「堕怒」** | 暴走不再结束，持续到战斗结束；暴走期间攻击骰变为 3d6+1。选择此节点后，**「沉静」「赎罪」永久禁用** |

### 6.3 双子（罗兰）：投出对子时触发

| 节点 | 效果 |
|---|---|
| 罗兰之声 | 投出对子时，追加一段攻击 |
| 并肩 | 追加的那段造成伤害时，怒气 −1（罗兰让他冷静） |
| 同心 | 对子的那一段必定穿透闪避 |
| 背靠背 | 被群体攻击时，每闪避或格挡一段，下一次攻击 +1 |
| 骨骰之约 | 主动：把一颗骰子改成另一颗的点数，强制对子（2 骰能，每场 1 次） |

> 2d6 投出对子的概率是 1/6。双子分支是两条路线都能搭配的通用分支，也是罗兰在故事里「一直在」的体现。

## 7. 结局

结局由**终极节点的选择**和**塔顶的最后一掷**共同决定：

| 结局 | 条件 | 内容 |
|---|---|---|
| **赎罪** | 选择「赎罪」，登顶 | 凯恩改写无誓之夜。罗兰活了下来，而他依旧是那个在城墙上看着家乡燃烧的守誓者。他在塔顶放下了剑。 |
| **堕怒** | 选择「堕怒」，登顶 | 凯恩改写守门之夜：他冲出城门，杀穿了蛮族大军，也杀死了所有挡在他面前的人。魔塔多了一层，守层的怪物叫「灰誓」。 |
| **（隐藏）双誓** | 未点任何终极节点，且最终首领战中投出对子 | 凯恩没有改写任何一夜，而是把罗兰的骰子放在塔顶，独自下了塔。 |
